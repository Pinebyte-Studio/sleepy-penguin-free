# SLEEPY-PENGUIN Free

Бесплатный таймер для Windows 10 и 11. По истечении выбранного времени выключает компьютер или переводит его в спящий режим.

![Интерфейс SLEEPY-PENGUIN Free](docs/screenshot.png)

- Настройка времени от 5 минут до 4 часов с шагом 5 минут.
- Предупреждение за минуту до срабатывания и возможность отмены.
- Русский интерфейс. Программа работает локально, без установки.

## Скачать

Откройте [раздел релизов](https://github.com/Pinebyte-Studio/sleepy-penguin-free/releases), скачайте `SleepyPenguin.exe` из списка файлов релиза и запустите его.
